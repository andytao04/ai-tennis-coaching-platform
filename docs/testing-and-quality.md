# Testing & Quality

The private codebase includes:

- Vitest for automated tests
- Testing Library for UI/component testing
- fast-check for property-based testing
- ESLint for static code-quality checks
- Zod for application-level schema validation

The project also maintains explicit commands for development, production builds, linting, automated tests, database migration, and seed-data creation.

The private repository contains a dedicated PWA testing guide covering installability and browser/device checks. The full suite is not mirrored here because it is coupled to the private implementation.
